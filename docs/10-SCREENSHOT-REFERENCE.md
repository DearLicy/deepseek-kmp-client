## 尺寸

上述 11 张文件均为 **1179 × 2556 px**。以 3 倍像素密度换算可得到 **393 × 852 pt** 的工作画板，这是重建假设，不是已验证的设备型号。

| 对象 | 工作画板初始值 | 依据与限制 |
| --- | --- | --- |
| 侧栏宽度 | 约 82–83%（约 324 pt） | 截图侧栏右边缘位置估计 |
| 顶部圆按钮 | 约 44–46 pt | 截图轮廓估计；点击区域至少 44 pt |
| 输入框左右留白 | 约 12 pt | 欢迎页/对话截图估计 |
| 输入框高度 | 约 110 pt，随内容变化 | 仅空输入状态估计，不写死生成态高度 |
| 输入框圆角 | 约 24–28 pt | 截图曲率估计 |
| 用户气泡 | 右对齐，最大宽度约 78% | 长文本自然换行 |
| 来源 Sheet | 底部起、可滚动 | 静态图可见形态；拖动过程未录制 |

Android 使用 dp/sp 与自己的安全区，不把整张 iPhone 截图直接当屏幕像素布局。系统状态栏、键盘、录音指示灯由系统提供，不能将截图中的时间、电量或灵动岛画进 App。

对原始 RGB 图像的以下区域统计最常见像素，保留复核坐标（左、上、右、下；单位 px）：

| 图片与裁剪区域 | 观察 |
| --- | --- |
| IMG_5167.PNG `(900,440,1100,580)` | 用户气泡填充 `#EEF3FD`、正文近黑 `#0F0F0F` |
| IMG_5157.PNG `(450,1100,700,1300)` | 鲸鱼区域主蓝像素 `#4C6DF5`、背景 `#FFFFFF` |
| IMG_5166.PNG `(250,1700,850,2100)` | 设置背景 `#F8F8F8`、卡片 `#FFFFFF` |

APK `resources.txt` 中 `color/primary` 有默认 `#426EFE` 和 night `#507BF2`。这说明截图版本、平台和组件可能使用不同蓝色，不能拿 Android 的主色值直接断言 iOS 所有图标都同色。

## 原生平台复刻方式

- 侧栏：保持一个聊天根视图，通过手势驱动位移；侧栏单独持有列表位置；不每次创建新的聊天实例。
- 输入区：文本/按住说话/附件/识别中为互斥状态；打开键盘时不保留附件面板占位。
- 思考与搜索：同一内容块模型投影成时间线，不把工具结果拼成正文，也不向用户伪造服务端未返回的步骤。
- Sheet：设置、音色、来源各有滚动容器和焦点恢复；关闭顶层 Sheet 时不退出底层页面。
- 弹窗：仅用户确认后删除对应本地记录；API Key 模式不显示“官方共享链接失效”这种无法兑现的云端效果说明。
- 动效：截图只支持位置/样式对比；时长、阻尼、手势阈值需后续录屏或真机验证。文档中的数值是实现起点。

原图包括用户提供的会话和个人资料画面，作为本地设计参考保存；不作为 App 内素材或公开宣传截图自动打包。
