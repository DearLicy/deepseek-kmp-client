# DeepSeek KMP 原生双端客户端：产品范围

## 1. 项目定位

本项目是一个使用 **Kotlin Multiplatform（KMP）共享逻辑 + Android Jetpack Compose + iOS SwiftUI/UIKit 原生 UI** 的 DeepSeek API Key 客户端。

产品目标分为两层：

1. **视觉与交互层**：以 所提供的 Android 2.8.0 APK 与 iOS 截图 的页面、组件、动效和资源为参照，尽可能做到 1:1 复刻。
2. **数据与能力层**：以 `deepseek-ai/chat-demo` 已公开的 API Key 接入方式为唯一业务数据面；不依赖官方 App 私有登录态、Pow、私有会话同步或 DSH Gateway。

本项目的“复刻”指 UI 壳和交互体验的复刻，不表示能够复刻官方 App 的服务端能力、账号体系或私有接口。

## 2. 固定约束

- 开发目录：仓库根目录。
- 临时文件：只允许放在 仓库根目录下的 `.tmp`，不使用系统全局临时目录。
- 客户端无需登录、短信、OAuth 或官方 App Token。
- 用户填写自己的 DeepSeek API Key 后即可开始对话。
- 成品要求：API Key 只进入平台安全存储，不进入共享普通状态、日志、崩溃报告或导出文件；当前骨架尚未接入安全存储。
- APK 主要作为 UI、动效、页面和资源证据；网络接入按 chat-demo 公开 API Key 合同实现。私有路由仅用于解释差异，不依赖登录态。
- `Whaleness/dsh-mobile` 不下载、不链接、不作为参考。
- 不连接 DSH Gateway，不实现 DSH 协议。
- Android 和 iOS 共享业务逻辑，UI 分别使用平台原生技术。

## 3. 用户核心流程

```text
首次启动
  -> 欢迎页
  -> 输入 API Key
  -> GET /models 校验（不产生费用）
  -> 进入新对话
  -> 选择深度思考 / 智能搜索 / 附加文件 / 语音输入
  -> POST /anthropic/v1/messages（SSE 流式返回）
  -> 展示思考、工具步骤、正文和引用
  -> 可复制、朗读、反馈、重新生成、续写
  -> 本地保存会话与草稿
```

## 4. 必须实现的产品能力

### 4.1 对话

- 新建对话、会话列表、会话标题、置顶、重命名、多选、删除。
- 用户消息、助手消息、思考折叠/展开、搜索步骤、来源列表、正文 Markdown。
- 流式输出、停止生成、重新生成、续写/继续生成。
- 会话本地持久化与导入/导出。
- 文本复制、朗读、点赞/点踩的 UI 状态与本地反馈入口。

### 4.2 深度思考

- 输入区“深度思考”开关。
- 请求中映射为 Anthropic-compatible `thinking: { type: "enabled" | "disabled" }`。
- 展示 `thinking_delta`，按思考块合并、计时、折叠。
- 思考结束状态显示“已思考（用时 N 秒）”，与截图一致。

### 4.3 智能搜索

- 输入区“智能搜索”开关。
- 请求中声明 `deepseek_web_search` 工具。
- 解析 `server_tool_use`、`web_search_tool_result`、`citations_delta`。
- 正文引用角标、来源卡片、底部“N 个网页”入口。
- 研究过程展示“正在搜索”“搜索到 N 个网页”“已阅读 N 个网页”等状态。

### 4.4 附件

- 拍照、相册、文件三个入口。
- 附件预览、删除、上传进度、失败重试。
- 图片走 Files API 的 `image` 文件块；其他文档走 `document` 文件块。
- 搜索开启时不能发送文件，客户端在 UI 层提前提示。

### 4.5 语音

- 普通输入态与“按住说话”态切换。
- 长按录音、松手发送、上滑取消。
- 录音波形、录音遮罩、蓝色渐变全屏反馈。
- 录音停止后调用 `/v1/tools/asr`，把识别文本填回输入框或按产品开关直接发送。
- 助手消息可朗读，TTS 音频按平台播放器播放。

### 4.6 设置

- API Key 配置与校验。
- 深色/浅色/跟随系统。
- 语言设置。
- 字体大小预览、跟随系统、滑块调整。
- 朗读音色选择。
- 数据管理：本地缓存、导入/导出历史、删除历史；不实现官方账号的训练数据开关。
- 帮助与反馈、服务协议、版本信息。

## 5. 明确不实现

以下能力属于官方 App 私有体系，不作为本项目当前功能依赖：

- 手机号、微信、Apple 或 OAuth 登录。
- 官方账号的历史会话云端同步。
- 官方 App 私有 API：
  - `/api/v0/chat/completion`
  - `/api/v0/chat/continue`
  - `/api/v0/chat/resume_stream`
  - `/api/v0/chat/stop_stream`
  - `/api/v0/chat/history_messages`
  - `/api/v0/chat/tts/*`
  - `/api/v0/asr/ws`
  - `/api/v0/file/upload_file`
- 官方 App 的 `voice_id` 动态列表和四音色私有下发。
- 官方 App 的 Pow、私有签名、私有 Header、隐藏登录态。
- 任何依赖官方私有接口稳定性的“破解式”接入。
- 服务端会话同步、多设备实时同步。

| 能力 | 官方 App 截图/APK 证据 | chat-demo API Key 路线 | 首版状态 |
| --- | --- | --- | --- |
| 对话 Shell、侧栏、设置、菜单 | 已确认 | UI 自实现 | 可 1:1 复刻 |
| 深度思考折叠与计时 | 已确认 | `thinking` + SSE | 可实现 |
| 联网搜索与来源 | 已确认 | `deepseek_web_search` + SSE | 可实现，视觉需数据驱动 |
| 文件上传 | 已确认 | Files API | 可实现 |
| 图片输入 | 已确认 | `image` 文件块 | 可实现，需 beta header |
| ASR 语音输入 | 已确认 | `/v1/tools/asr` | 可实现 |
| TTS 朗读 | 已确认 | `/v1/tools/tts` | 可实现，当前固定版本示例只枚举 2 个音色 |

| 通话式实时语音 | 截图有入口 | 无公开聊天通话协议证据 | 不做或仅做录音转写入口 |
| 官方私有 Pow/签名 | APK 有痕迹 | 不使用 | 不做 |

## 7. 验收边界

首版发布必须分别验证：

1. KMP 共享逻辑单元测试通过。
2. Android 工程可编译、可安装、关键页面可交互。
3. iOS 工程可在 macOS/Xcode 环境编译；当前 Linux 环境只能做静态审查，不能声称已编译。
4. 使用假 API Server 的端到端流式测试通过。
5. 使用真实 API Key 的手工冒烟测试通过，但不得把 Key 写入仓库或日志。
6. 设计验收覆盖浅色/深色、窄屏/大屏、思考展开/收起、搜索来源、语音录制、设置 Sheet。

任何未实际运行的构建、设备测试或真实接口验证，都必须在交付说明中明确标注为未验证。
